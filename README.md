# DRIVEON 🚗

A modern, premium, and responsive car dealership landing page designed for a fictional automotive brand. DRIVEON offers an elegant browsing experience with interactive car listings, bilingual support, and customer-friendly features.

**Features:**
- Premium automotive UI/UX
- English & Bengali language switcher
- Responsive design for mobile and desktop
- Interactive car search, filtering, and sorting
- Car showcase with specifications and pricing
- Customer testimonials and FAQ accordion
- WhatsApp contact integration
- Contact form with validation
- Smooth scrolling and animations

**Tech Stack:** HTML5, Tailwind CSS, Vanilla JavaScript
